# Logo AfriAutomate

Déposer ici toutes les déclinaisons du logo :
- `logo-principal.svg` — version vectorielle de référence
- `logo-fond-clair.png` — version haute résolution pour fonds clairs
- `logo-fond-sombre.png` — version pour fonds sombres (#0D1117)
- `favicon.ico` / `favicon.png` — pour site et signatures email
- `monogramme.svg` — version réduite (réseaux sociaux, avatars)

> Règle : jamais déformer, jamais re-coloriser hors palette charte.
